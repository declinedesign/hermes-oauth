Privacy Policy

Hermes Personal Assistant  ·  Last updated 2 November 2026

This policy describes how the Hermes personal assistant handles data from a Google Account. The tool has one user: the owner of the computer where it runs.

1. Data the tool reads

With the owner's consent, the tool reads Google Calendar events, Gmail messages, Google Drive file metadata, Google Contacts, Google Sheets and Google Docs that belong to the owner's own account.

2. Where the data goes

The data stays on the owner's computer. The tool does not send Google data to any third party. The tool does not sell, rent, or share Google user data.

3. Why the tool reads the data

The tool reads the data only to prepare short summaries and reminders for the owner. It does not use the data for advertising, profiling, or training machine learning models.

4. Storage and retention

Summaries and reminders are stored as local files on the owner's computer. OAuth tokens are stored in a local file that only the owner can read. The owner can delete these files at any time.

5. Data sharing

Google user data is not transferred to others. Google user data is not used by third parties. The only exception is when the owner asks the tool to send a message, for example a reminder to the owner's own Telegram account.

6. Revoking access

The owner can revoke the tool's access at any time at myaccount.google.com/permissions.

7. Contact

Questions about this policy: declinedesign@gmail.com
