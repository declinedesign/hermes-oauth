Hermes Personal Assistant

A private, single-user automation tool.

Hermes is a personal software assistant. It runs on one computer, owned by one person, and it is not distributed to the public. It is not a service and it has no other users.

What it does

Hermes reads its owner's own Google Calendar and Gmail account to produce short reminders. For example, it can warn about a calendar conflict during an upcoming trip, or list important unread mail.

How it uses Google data

The tool uses the Google OAuth API with the account owner's consent. It reads calendar events and email messages. The data stays on the owner's computer. It is not sent to a third party, and it is not sold or shared.
